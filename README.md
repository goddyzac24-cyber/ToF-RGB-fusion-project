# Lightweight ToF–RGB Dense Depth Fusion

This repository documents a research prototype that combines frozen Depth Anything 3
dense depth with an 8×8 multi-return VL53L5CX ToF sensor. The current system includes
sensor calibration, real and simulated data pipelines, lightweight V4/V6 fusion models,
and a live comparison against an Intel RealSense D455f reference.

Read the [comprehensive project progress report](PROJECT_PROGRESS_REPORT.md) for the system
design, completed experiments, quantitative results, limitations, and next steps.
